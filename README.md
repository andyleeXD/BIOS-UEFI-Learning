# Bios-Note
BIOS-UEFI-Learning：個人 BIOS、UEFI 與 BMC 相關知識學習筆記

# 主題
 • 以 Firmware / Platform Management 為主軸，持續整理 x86 Architecture、BIOS / UEFI、BMC 與 Embedded Linux 等底層系統相關知識。
 • 已完成並公開 x86 Architecture 基礎筆記，內容涵蓋 CPU Instruction Cycle、Register、CPU Mode、Paging、MMIO / Port I/O、多核心同步與 Cache Coherence 等主題。
 • BIOS / UEFI 學習路徑涵蓋 PC Boot、UEFI Boot Flow、Protocol、Driver、PCIe、ACPI 與 EDK II，並逐步加入實作與 Debug 練習。
 • BMC 學習路徑規劃涵蓋 BMC Architecture、Embedded Linux、U-Boot、I²C / SMBus、IPMI、Redfish、Sensor / Fan / Power Management，以及 OpenBMC 基礎架構。
 • 透過 Obsidian 建立系統化技術筆記，並將學習成果持續整理至 GitHub，作為 Firmware Engineer 轉職的技術累積與實作紀錄。
